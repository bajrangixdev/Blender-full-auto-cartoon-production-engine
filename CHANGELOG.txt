Cartoon Studio Pro 1.7.7 (characters continue from where they stopped)
  * New option "Continue from last shot" (Shot Builder, under Keep my character placement, ON by default):
    each shot starts every character where it ended in the previous shot, facing the way it was facing,
    so a character that ran somewhere no longer jumps back to its start place on the next shot.
    The first shot a character appears in still uses its own placement. Turn it OFF for the old behaviour.
  * Inside one shot with several action ranges, each action starts where the one before it ended.
  * A walk / run action range that goes to a new place now turns the character towards that place
    (before, only a walk in the first action range turned).
  * Cameras now frame a character's whole path in a shot with several action ranges.

Cartoon Studio Pro 1.7.6 (characters keep the position, rotation and scale you set)
  * The black plus-sign "root" empty now sits ON the character (at its origin) instead of at the world
    origin, and the character is parented to it without moving. Moving / rotating / scaling the plus
    sign moves / turns / scales that one character around its own pivot.
  * New option "Keep my character placement" (Shot Builder, above Build Episode, ON by default):
    every shot starts with each character exactly where, how big and how turned you placed it.
    Standing characters are not turned; walkers walk the way they face. Turn it OFF to use the
    X / Depth boxes of each shot (they are now real world positions, no longer added on top of the
    character's own offset).
  * Build Episode no longer touches character scale. Old generated roots (which sat at the world origin
    and could scale / tilt characters around it) are reset and re-anchored on the first build.
  * Fixed hand-edit detection on rebuild: it now compares with what the build keyed at the SAME frame,
    so building from any frame no longer adds phantom offsets, turns or tilts.
  * Duplicated / copied rigs that shared one root now get their own root each.
  * Camera aim-point empties are hidden in the viewport (they still drive the cameras).

Cartoon Studio Pro 1.3.0  (from 1.2.1)  - RIG MARKERS (like Mixamo's auto-rigger)

NEW: place the joints yourself with small circles
  Character Library > "Fit a skeleton with markers":
    1. Select the character mesh (T-pose, arms out, facing the front) > "1. Add Rig Markers".
       15 coloured circles appear, already placed by the automatic guess, and the view switches to FRONT:
       Head Top, Chin, Neck Base, Shoulder L/R, Elbow L/R, Wrist L/R, Pelvis, Groin, Knee L/R, Ankle L/R.
    2. Drag each circle onto its joint (G key or move tool). They only move left/right and up/down.
       "Mirror Left to Right" copies one side onto the other.
    3. "2. Build Skeleton From Markers" builds the Mixamo-named skeleton so its joints sit exactly on your
       circles, skins the mesh (smooth weights) and adds the character to the library.
  Hands and feet follow the length of the arm / leg you marked. Feet are kept on the floor.
  Needs one Mixamo animation .fbx imported first (that is where the skeleton shape comes from).
  Do NOT use Blender's Rigify "metarig": its bone names are different, Mixamo animations cannot drive it.

Cartoon Studio Pro 1.2.1  (from 1.2.0)  - RIGGING FIXES

SKIN WEIGHTS - joints no longer tear
  * Old fallback gave every vertex to ONE nearest bone (100%), so arms, sleeves and hands stretched and
    separated. Now every vertex gets smooth weights from its nearest 1-3 bones (new file rigfit.py).
  * Finger / toe / eye bones no longer take weight when skinning by distance, so a mitten hand or round
    foot moves as one piece with its hand/foot bone.
  * Blender's automatic weights are still tried first. A mesh where they failed (or covered less than
    80% of its vertices) gets the blended weights. Stray vertices left without weight are fixed one by one
    (before, a half-failed skin counted as success and those vertices stayed behind).
  * Messages now say "smooth", "smooth (N stray vertices fixed)" or "blended" weights.

SKELETON FITS THE BODY
  * The built-in skeleton used to be a human template just scaled to the model's height. It now measures
    the mesh surface and moves the hips, neck and leg spacing to where THIS body has them, so big-head /
    short-leg cartoon characters line up. If it cannot detect them reliably it keeps average human
    proportions and says so in the message.

BUG FIXED: duplicate operators
  * characters.py contained two copies of "Add Characters" and "Add Skeleton To Selected Mesh". The older
    copies came later in the file and overrode the new ones, so the T-pose / A-pose skeleton button never
    ran (it asked for a Rig Template file instead). The old copies are removed.

ANIMATION LIBRARY
  * "Register Actions in This File" now also remembers the skeleton shape from an armature in the scene
    (before only importing an animation file did), so rig-less characters can still get a skeleton.

NOT CHANGED: Mixamo "Hips" movement is not rescaled to the character's size. If a big movement
(flip, jump) throws the body too far, tell me and this can be added.

INSTALL: remove the old Cartoon Studio Pro add-on, restart Blender, Edit > Preferences > Add-ons >
Install from Disk > CartoonStudioPro_v1_2_1.zip. Then: import ONE Mixamo animation .fbx first, then add
characters. Old characters keep their old skin: remove them and add them again.

Cartoon Studio Pro 1.2.0  (from 1.1.3)

CHARACTER LIBRARY - accepts every model now
  * No more rejection for "not a T-pose" / "no skeleton" / "not skinned".
  * Skeleton + skinned, any pose ........ accepted (a note is logged if the pose is not a T-pose)
  * Skeleton, mesh not attached ......... mesh is skinned to the skeleton automatically
  * Mesh with no skeleton ............... auto-rigged with the Rig Template if one is set,
                                          otherwise kept as a one-piece character (placed, moved, filmed)
  * Wrong size / wrong direction ........ scaled to "Character height", "Model faces" turns it to the camera
  * Select SEVERAL files at once in Add Characters.
  * Animations with different bone names (mixamorig: / mixamorig1: / none / Arm.L ...) are re-mapped automatically.
  * Fixed: zip characters were never packed when extracted to a temp folder.

TWO SHOTS FREEZING - fixed
  * Cause: every shot added a new NLA track whose strip held its first/last pose outside its own frames,
    so the newest track froze every shot before it.
  * Now: one track per character, strips never overlap and never hold.

SHOT TIMELINE
  * Shots follow each other: shot 1 = frames 1-100, shot 2 = 101-200 ... (default length 100).
  * Frame range is shown in the shot list and in the shot box (live, before building).
  * New buttons: Go To Shot, Play Shot, Play All.

MORE CHARACTERS
  * Character A, B and unlimited extra characters per shot, each with X (left/right) and Depth.
  * "Characters per shot (auto)" for Story to Shots, "Spread Evenly" for any shot.

CAMERA - planned from the action
  * New default "Auto (follows the action)": walking/running -> tracking shot that travels with the
    character; jump -> low angle with tall frame; fight/dance -> slow orbit; talking alone -> medium
    close-up with push-in; two people -> establishing two-shot, then over-the-shoulder / reverse shots;
    3+ people -> group shot with everybody framed; sad = slightly high, angry = slightly low;
    first shot = establishing wide, last shot = slow pull-out; the same camera is never used twice in a row.
  * Framing is calculated from lens, aspect ratio and character height, so nobody is cut off.
  * Camera moves during the shot (push-in, tracking, orbit). The plan is shown under the Camera menu.
  * Manual types still exist: Wide, Full body, Medium, Close-up, Over shoulder, Two-shot, Low, High, Tracking, Orbit.

MOVEMENT
  * Walk / run animations that stay in place now travel across the scene and turn the way they go
    (toward the other character when there is one). Set "Walk distance" to override.
  * Standing characters turn partly toward each other.

INSTALL: remove the old Cartoon Studio Pro add-on, restart Blender, then Edit > Preferences > Add-ons >
Install from Disk > choose CartoonStudioPro_v1_2_0.zip. Blender 4.2 or newer.
Old .blend files: press Build Episode once after updating.
